# 腕上节律：现场操作（单页）

准备：项目依赖、官方 SDK/大赛镜像、已有 466×466 VVD、本次正式 Release、完整实录 MP4。RPK 的大小、SHA-256 和源码来源见交付目录 `evidence.json`。电脑离线前完成依赖与 SDK 准备。本轮录像为静音。工具从已安装依赖的源码项目根目录运行；ZIP不包含SDK或node_modules。

1. 在 PowerShell 进入 `F:\项目\openvela`；执行 `scripts\start-review.ps1 -CheckOnly`。有多台设备时指定 `-Serial`。
2. 执行 `scripts\start-review.ps1 -VvdName WristRhythm_Review_20261012 -Rpk <本次交付目录\com.openvela.wristrhythm.release.1.0.0.rpk> -OutputDirectory <本次现场日志目录>`。失败时按工具给出的日志位置处理；没有成功安装日志时不要继续宣称已安装。
3. 核对 `screenshots/launched.png` 和模拟器画面确为首页。休眠时按一次电源键唤醒。冷启动先等待系统表盘和服务完成启动；扫描期间安装超时则保留日志后重试。缺失实例时指定已有 `-SdkHome`、`-VvdName`，不重新下载。
4. 解释首页数据状态。镜像样本是模拟器提供的数据，不能称人体采集。无数据也可点“稳态 60”。
5. 完整运行 60 秒，讲解吸气、停留、呼气、节奏原因；完成后查看结果，再点“完成”。无有效新样本时解释“无法比较”。
6. 进入“节奏拳”，展示目标、命中和加权得分；如使用 `review-plans.js positive` 注入，必须说明“模拟器传感器输入，不代表真人动作识别准确率”。正向脚本只负责该独立场景，不能在讲解流程中不经说明接管页面。
7. 没有动作数据时展示真实提示，点“结束并返回首页”。呼吸“结束训练”也是主动返回首页，不生成完成全程的结果。
8. 主流程异常时播放本次 `emulator-video/emulator-sensor-input-full.mp4`。完整录像保留真实时长和模拟标记。本轮没有加速节选。

演示前本地播放一次完整视频并检查画面输出设备。大量反复换包后若日志出现错误24或uv_loop_init失败，保留日志，仅重启本评审实例、等待表盘后重试；不要清理其他实例。训练期间的Home后台测试与重启恢复是不同场景。备用视频、截图和包均来自同一回执指定的最终 Release。细节见 [验证矩阵](verification-matrix.md)、[故障应对](故障应对.md)。
