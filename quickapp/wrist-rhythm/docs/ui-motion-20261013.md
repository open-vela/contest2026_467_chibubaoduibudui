# 持续开启动效与实时演示

按后续要求移除首页动效选择按钮和切换事件，入口向五个页面传入固定的 `motion-full`。品牌标题居中。呼吸规则、60 秒／30 秒计时、健康比较与拳击计分保持原样。

首页数据脉冲改为 640ms 缓入缓出；操作反馈 180ms，人物及完成反馈 320ms。节拍环使用 280ms 渐入渐出与 40ms 的圈间延迟，避免突然亮灭。呼吸环在吸气、停留、呼气及下一周期交界处保持亮度端点一致，停留期间保持静止。

实时演示使用正式 RPK 的模拟器画面与真实点击。SDK 连续画面流通过本地 SSE 推送，浏览器先解码、再随绘制帧提交，并丢弃积压的中间帧。隐藏标签停止订阅并取消底层截图 RPC，旧流的取消回调不会关闭新连接；重新打开页面会激活应用。未承诺固定 60fps，实际速度受模拟器渲染和编码影响。

演示入口：<http://127.0.0.1:8202/>。点击表盘进入现有流程，“重启演示”结束当前训练并返回首页。应用健康数值来自模拟器；动作连接仍可能不可用。
