# 现场故障应对表

| 故障 | 已可用的应对 | 需要保留的限制 |
| --- | --- | --- |
| 无健康数据 | 解释读取中/不支持/待更新；直接开始完整呼吸；结果按实际显示无法比较 | 不补数字，不承诺健康改善；异常渲染证据是独立故障包 |
| 无动作数据 | 展示“无法记录出拳”、0 分；点“结束并返回首页”，继续呼吸主流程 | 不点击加分；传感器注入需明确说明模拟输入 |
| 安装失败 | 查看本次 device.log；核对 RPK 路径与 SHA、设备序列号、镜像；工具未确认 executeInstall 成功就不报告成功 | 冷启动扫描时先等表盘/服务后重试；日志出现错误24或uv_loop_init失败时保存记录，仅重启本评审实例再试。本轮已实际恢复；具体底层原因未完全定位。可用本次视频作备用 |
| 模拟器无法启动 | 核对已有 SDK/VVD、端口、ADB及实际进程；SDK注册不等于实例存活，连接超时则保留日志并核对该实例残留；可转本次视频和截图 | 不关闭无关实例、不临时下载整套 SDK；截图不能冒充运行验收 |
| 画面不动 | 检查是否休眠，按一次电源键唤醒，再核对倒计时与本次 page show 日志 | 最后一帧截图可能滞留，不能用它推断前台状态 |
| 视频播放失败 | 用本地既有播放器重新打开；核对文件哈希；仍失败则展示本次各阶段截图及结果，保留播放错误 | 截图说明不能代替完整实时训练；本轮保存完整离线解码及实际本地浏览器完整播放记录 |
